A simple **C++ console-based Dental Clinic Management System** for managing patients, dentists, services, and appointments.

## ✨ Features

* Add and register patients
* Automatically assign patient IDs
* Assign dentists and dental services
* Display all patient information
* Display appointments
* Discharge patients after checkup
* Display service prices
* Track dentist workload

## 🧱 C++ Concepts

This project demonstrates:

* `struct`
* Arrays
* Functions
* Pointers
* Dynamic memory (`new` / `delete`)
* **Singly linked list**

Patients are stored dynamically using a linked list:

```text
[Patient 1] → [Patient 2] → [Patient 3] → nullptr
```

## ⚙️ Run the Project

Compile with a C++ compiler:

```bash
g++ main.cpp -o dental_clinic
```

Run:

```bash
./dental_clinic
```

On Windows:

```bash
dental_clinic.exe
```
